EMA trend trading bot for Coinbase Wrapped BTC (cbBTC) on 1-minute bars: it goes long when EMA(12) crosses above EMA(144) with positive 30-bar momentum, and exits on the cross back, a 2% trailing stop, or a 1.5% take-profit. Long only, one position, 37.5% of equity per entry. It speaks the agent-fun/bars-replay/v1 protocol on stdin/stdout.

## Run it
